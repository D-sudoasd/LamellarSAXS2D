> 文档版本：v2.0

> 当前项目版本：0.1.0 Alpha

## 0. 优化后的任务定义

### 0.1 可直接执行的任务提示词

以当前 LamellarSAXS2D 0.1.0 Alpha 代码、README 中的四视图界面、Grubb 2016/2021 论文所界定的科学边界，以及本地真实数据包 2#_no50s_375_2_iso 为依据，先完成环境、输入契约、几何标定、mask、ridge/lobe、双椭圆、full2d、批处理、GUI、导出、质量门、不确定度和可复现性建设；再按照“同模型合成数据 → 独立物理合成数据 → 少量真实 pilot → 完整真实序列”的顺序验收。

任何阶段都必须同时给出：

- 输入文件和前置依赖；
- 要修改或新增的模块；
- 输出文件和证据；
- 自动化测试；
- 定量通过阈值；
- Go / No-Go 判断；
- 暂停条件；
- 用户能够独立复核的方法。

不得把 success=True、低 RMSE、椭圆拟合成功或四叶图样相似，直接解释为唯一三维层片结构、取向参数或材料变形机制。真实原始数据只读使用，结果写入新目录，不得提交或上传 data_local/ 和 CHANGELOG.md。

### 0.2 本计划的五条路线

1. **工程路线**：环境、接口、CLI、GUI、批处理、导出、安装包与 CI。
2. **算法路线**：ridge、lobe、双椭圆和 full2d 的真值恢复、稳健性与失败识别。
3. **科学路线**：q 标定、mask、校正状态、单位、不确定度、可辨识性与解释边界。
4. **真实数据路线**：数据包预检、pilot、重复性、完整序列和最终签字验收。
5. **物理模型路线**：经验测量平台通过验收后，再独立实现 Grubb 风格物理正演；正演与经验拟合不互相替代。

### 0.3 总验收原则

项目只有同时满足以下三项，才可称为“真实实验可用”：

- **跑得通**：干净环境、CLI、GUI、批处理、导出和安装包均可复现。
- **量得准**：在有真值或人工共识标注的数据上达到预先锁定的误差阈值。
- **知道何时不可信**：低覆盖、低信噪比、边界命中、病态参数、校准缺失和模型失配必须明确返回 WARN/FAIL，不能静默给出看似合理的数值。

## 1. 对本项目最终目标的统一理解

### 1.1 一句话目标

LamellarSAXS2D 的最终目标，是成为一套面向取向层片/蝴蝶状二维 SAXS 图样的**可校准、可测量、可拟合、可批处理、可追溯、会拒绝不可靠结果**的科研分析平台，并在独立证据充分时支持物理正演比较。

### 1.2 三层能力必须分开

| 层级 | 要回答的问题 | 当前模型可否回答 | 输出边界 |
|---|---|---:|---|
| L0 数据与几何层 | 图像是否读对？q 是否标定？mask 和校正是否明确？ | 部分可以 | 图像、q-map、有效像素、provenance |
| L1 表观测量与经验拟合层 | lobe 在哪里？ridge 轨迹如何？双椭圆能否描述图样？ | 当前主线 | q*、角度、ridge、a/b/theta、full2d 经验参数及质量 |
| L2 物理正演与结构约束层 | 给定层片堆叠、取向和展宽，能否预测二维图样？ | 尚未完整实现 | 单向预测、模型比较、不确定度；不默认做唯一逆解 |

L0 不合格时不得进入 L1；L1 未通过泛化与质量门时不得进入 L2。

### 1.3 README 界面图是功能基线，不是科学验收证据

README 截图所示界面应作为 GUI 完成度的视觉和交互基线：

- 左侧四视图：Observed、Model、Residual、Overlay；
- 上方页签：Refinement、Measurements / Profiles、Batch、Evolution；
- 右侧参数表：Value、Min、Max、Vary、Expr、Unit、Stderr；
- 操作：Preview、Optimize、Cancel、Ignore late result、ROI；
- 状态栏：RMSE、ndata、flags、coverage 等。

最终界面不能只“看起来像截图”，还必须满足：

- Observed 与 Model 使用一致强度色阶；
- Residual 以 0 为中心，正负残差可辨；
- mask 像素不参与拟合，并在图上可识别；
- Overlay 中 ridge、lobe、椭圆和排除区来源明确；
- 参数单位、边界、是否固定、表达式绑定和不确定度一致；
- WARN/FAIL 不能被绿色“Optimize complete”掩盖。

### 1.4 明确不做的事情

当前项目完善阶段不包括：

- 从单张二维 SAXS 图直接唯一反推出 phi/alpha/psi 等三维结构角；
- 把 theta_deg、phi_app_deg 与论文同名符号直接画等号；
- 仅凭拟合曲线判断相变、位错机制、层片旋转或变形机制；
- 自动重复暗场、背景、monitor、transmission、厚度或绝对 K 因子校正；
- 在真实数据验收前进行全序列机制解读；
- 暂时实现跨帧 global/shared joint refinement。

### 3.4 人工标注与真实参考

真实数据没有绝对的“椭圆结构真值”，因此使用以下协议：

1. 从 R0 选择 RT、初期、中期、末期以及至少 2 个困难/失败候选帧；
2. 从 R1 每种图样至少选择 5–10 帧；
3. 两名标注者在不知道算法结果的条件下，独立标注有效区、beamstop、streak、overlap、lobe 中心和 ridge；
4. 分歧由第三次复核形成 consensus；
5. 记录标注者、软件、坐标系、图像版本和时间；
6. 阈值以重复标注误差和仪器分辨率为依据锁定，不以算法当前表现反向放宽。

如果暂时只有一名领域专家，可采用间隔至少一周的两次盲化重复标注作为过渡，但证据等级必须标为“单人重复”，不能等同于双人独立标注。

论文图片、表格和截图只可作为定性对照，不能冒充原始数据真值。

## 4. 全局科学与软件合同

### 4.1 q、坐标与周期

- 内部统一使用 q = 2πs；
- 物理 q 统一规范为 nm^-1；
- Å^-1 → nm^-1 乘以 10；
- 只有 q_unit=nm^-1 且 PONI 有效时，才允许输出 d=2π/q；
- pixel-q 必须携带 uncalibrated_pixel_q，图轴不得写 nm^-1；
- detector pixel、pixel-q 和物理 q 参数必须在 schema 中分开命名。

### 4.2 mask 极性与统一拟合域

统一约定：

- valid_mask=True：该像素有效；
- external mask=True：该像素无效；
- ROI exclusion：该像素无效。

最终拟合域必须显式等于：

$$
\text{fit\_valid}=
\text{finite}(I,q_x,q_y)
\land \text{detector\_valid}
\land \neg \text{external\_mask}
\land \neg \text{ROI\_exclusion}
\land (q_{\min}\le q\le q_{\max})
\land \text{weight\_valid}.
$$

每个结果至少导出：

- image_pixel_count；
- finite_pixel_count；
- detector_valid_count；
- q_window_pixel_count；
- roi_excluded_count；
- fit_pixel_count；
- sampled_pixel_count；
- 最终 fit_valid_mask 的 NPZ 数组。

### 4.3 校正状态

每个输入必须声明：

- raw_counts；
- external_recipe_declared；
- partially_corrected；
- fully_corrected_external；
- unknown。

当前 R0 应标记为 external_recipe_declared，并分别记录已执行的 dark/background/monitor/transmission/固定厚度/绝对 K 因子，以及尚未烧入强度的 solid-angle/polarization。软件不得自动重复任何已声明步骤。若状态为 unknown，preflight 至少返回黄色警告；涉及绝对强度比较时，unknown 或关键修正状态未确认均返回红色阻断。

不确定度另设 uncertainty_state：none、partial、complete、unknown，并记录来源 dataset/文件、单位和包含的误差分量。当前 R0 为 partial；局部拟合 covariance、bootstrap 区间和探测器测量不确定度必须分栏保存，不能相互冒充。

因此，R0 当前可用于几何、表观形状、ridge/lobe 和相同处理条件下的相对比较。在 solid-angle/polarization 尚未按既定流程处理、绝对强度不确定度不完整时，不得把 full2d 的幅度参数或强度残差解释为绝对散射强度验证。

### 4.4 结果状态必须分层

每个拟合结果同时包含：

- solver_status：优化器是否完成；
- numerical_status：条件数、边界、有限值、收敛一致性；
- scientific_status：PASS / WARN / FAIL；
- failure_reasons：结构化原因列表；
- model_scope：empirical / physical-forward；
- interpretation_limit：apparent geometry / nonunique inverse problem。

solver_status=success 不是最终 PASS。

### 4.5 统一证据包

单帧输出目录至少包含：

- summary.json：严格 JSON，不允许 NaN/Infinity；
- arrays.npz：observed、model、residual、q/qx/qy、mask、ridge、fit domain；
- parameters.csv：值、单位、边界、vary、expr、stderr；
- observed.png、model.png、residual.png、overlay.png；
- quality.json：阈值、flags、PASS/WARN/FAIL；
- provenance.json：输入、标定、mask、配置、代码、依赖和时间 hash。

批处理额外输出：

- frame_summary.csv；
- parameters_long.csv；
- ridge_points.csv；
- ellipse_fit.jsonl；
- manifest.json；
- results.npz；
- evolution.png；
- run_report.md。

## 5. 定量验收矩阵

以下阈值分为两类：

- **固定阈值**：接口、hash、shape、有限值、mask 极性等可以直接判定；
- **暂定科研阈值**：需在重复人工标注、仪器分辨率和 pilot 结果出来后冻结。冻结前不得为了“让算法通过”而修改阈值。

### 5.1 输入、几何和 mask

| ID | 指标 | 暂定/固定门槛 | 证据 |
|---|---|---|---|
| IO-01 | 原始文件保护 | 输入 SHA-256 运行前后完全一致 | hash 清单 |
| IO-02 | 数组读取 | shape、dtype、强度逐元素保持；无隐式归一化 | fixture 比较 |
| IO-03 | 多帧/多 dataset | 歧义时 fail closed；显式 selector 可读 | 自动测试 |
| GEO-01 | 同版本 pyFAI q-map | q：float64 暂用 rtol≤1e-10、atol≤1e-12，float32 按 dtype 机器精度另定；chi：先计算周期化角差，再用相应浮点容差；固定 pyFAI 版本 | 数组差异报告 |
| GEO-02 | 实际标定标准 | q 峰误差 ≤0.5%，或 ≤峰宽的 0.1 倍，取更严格者 | 标定报告 |
| MASK-01 | mask shape/极性 | 与图像完全一致；已知像素逻辑逐点一致 | mask fixture |
| MASK-02 | 拟合域 | 各分解计数与最终 mask 精确闭合 | quality.json + NPZ |
| UNIT-01 | 未标定数据 | 必须为 pixel-q；禁止导出物理周期 | JSON/图轴检查 |

chi 的周期化差定义为：

$$
\Delta\chi=\operatorname{atan2}
\left[\sin(\chi_{\mathrm{test}}-\chi_{\mathrm{ref}}),
\cos(\chi_{\mathrm{test}}-\chi_{\mathrm{ref}})\right].
$$

不得用未周期化的 chi_test - chi_ref 直接判定几何误差。

### 5.2 ridge、lobe 与椭圆

高信噪比 T1 的暂定门槛：

| ID | 指标 | 暂定门槛 |
|---|---|---|
| RIDGE-01 | ridge detector 坐标中位误差 | ≤0.5 pixel |
| RIDGE-02 | ridge detector 坐标 95% 误差 | ≤1.0 pixel |
| RIDGE-03 | ridge F1 | ≥0.90 |
| RIDGE-04 | mask 内误检 | 0；被排除像素不得进入有效 ridge |
| LOBE-01 | lobe 角度误差 | ≤1° |
| ELL-01 | a、b 相对误差 | 各 ≤3% |
| ELL-02 | theta 误差 | ≤1° |
| ELL-03 | center 误差 | ≤0.5 个等效 detector pixel |
| ELL-04 | 重复运行确定性 | 同输入、配置、seed 的结果在数值容差内一致 |
| ELL-05 | 重复曝光稳定性 | 高质量真实重复帧的表观参数 CV 暂定 ≤5% |

ridge 还必须同时报告 q-space 误差（nm^-1）。若需要把 q-space 误差换算成“等效 pixel”，必须使用该 ridge 点处 q-map 的局部 Jacobian，并把换算方法与 Jacobian 一起保存。

T2 独立物理合成数据采用更贴近图样宽度的门槛：

- ridge 误差 ≤局部 FWHM 的 0.25；
- 图样类别识别准确率 ≥90%；
- 在相同坐标、mask、平滑和拟合范围下，只比较投影图样的 ridge/lobe/ellipse 表观轨迹：a、b 相对误差暂定 ≤5%，偏心率使用绝对误差，tilt 使用绝对角度误差（暂定 ≤1°或按标注重复性冻结）；
- 对非椭圆、重叠过强或信息不足的样本，正确 FAIL/WARN 也算通过，静默给出高置信结果算失败。

T2 保存的层片姿态、堆叠和结构角真值只用于验证独立生成器、研究非唯一性和检查模型失配，不能作为当前经验 full2d 应当直接恢复的反演真值。

### 5.3 full2d 与质量门

full2d 必须使用留出像素、留出 sector 或留出象限，不能只报告训练像素 RMSE。

建议输出：

- fit 与 withheld 的 normalized RMSE；
- 有可靠计数模型时的 Poisson deviance；
- 残差均值、尺度、空间自相关和四象限偏差；
- scaled-Jacobian condition number；
- bound flags、参数相关矩阵；
- multi-start 解之间的分散度；
- fit/withheld 性能比。

暂定质量分级：

| 规则 | PASS | WARN | FAIL |
|---|---|---|---|
| 有效数据 | fit 像素充分且覆盖主要分支 | coverage 边缘 | 无有效像素或关键分支缺失 |
| 多初值 | 主参数收敛到同一解族 | 有两个近似解族 | 解强依赖初值 |
| scaled condition | < 1e8 | 1e8–1e12 | > 1e12 或非有限 |
| 边界 | 关键参数未触界 | 非关键参数触界 | 关键几何参数触界 |
| 留出性能 | withheld 与 fit 相近 | withheld 明显变差 | 留出区失效或结构化残差 |
| 残差 | 无明显空间结构 | 局部结构残差 | 系统性四象限/条纹/峰位残差 |

条件数阈值只有在参数做无量纲缩放后才可使用；若未缩放，不得依据原始条件数自动判定。

scaled condition 的实现合同为：

- 只保留实际独立变化的自由参数；fixed 参数和由 Expr 绑定的从属参数不进入列空间；
- 每列按参数的允许范围缩放；没有有限范围时使用 max(abs(value), 典型物理尺度, 机器精度保护值)；
- J 是实际优化目标中已经应用 sigma/weights 和残差尺度后的 Jacobian；对缩放后的 J 计算 2-范数条件数，即最大奇异值/最小保留奇异值；
- 默认奇异值阈值为 max(m,n) × machine_epsilon × largest_singular_value；没有高于阈值的最小奇异值时 condition=Infinity；
- 奇异值截断阈值、参数尺度和自由参数顺序写入 quality.json；
- 不使用 J 转置乘 J 的条件数代替，因为它会平方放大病态程度。

### 5.4 不确定度与失败识别

至少覆盖：

- 噪声 Monte Carlo；
- detector sector/block bootstrap；
- PONI、波长、距离、像素尺寸扰动；
- mask 边缘膨胀/收缩；
- q-window 与背景选择扰动；
- ridge 方法、平滑参数、初值和随机采样敏感性。

暂定门槛：

- 每个代表条件 100–200 次重复；
- 95% 区间经验覆盖率 90–98%；
- 无效结果被错误标为 PASS 的比例 ≤5%；
- 报告 bias、median/IQR、95% 区间、失败率和参数相关性；
- 统计噪声不确定度与分析选择不确定度分别报告，不能混成一个 stderr。

### 5.5 真实数据

| ID | 指标 | 暂定门槛 |
|---|---|---|
| REAL-01a | ridge 点/区域一致性 | precision、recall 和 F1 分别报告，F1 暂定 ≥0.90 |
| REAL-01b | lobe 角度一致性 | 周期化绝对角度误差，暂定 ≤1°或按重复标注冻结 |
| REAL-01c | 连续拟合参数一致性 | ICC 与 Bland–Altman 同时报告；不能用 F1 替代 |
| REAL-01d | mask 一致性 | 像素级 precision、recall、F1 分别报告 |
| REAL-02 | 高质量重复帧 | 表观参数 CV ≤5% |
| REAL-03 | pilot 有效帧 | 固定 8 帧：4 个阶段代表帧 + 至少 4 个困难/负例；高质量候选必须 PASS，困难/负例允许 WARN/FAIL 但原因必须正确 |
| REAL-04 | 合理 mask/PONI 扰动 | 结果差异不超过合并 95% 区间，或进入 WARN/FAIL |
| REAL-05 | independent / warm-start | 差异落入合并不确定度；路径依赖被显式标记 |
| REAL-06 | 正序 / 逆序 warm-start | 不得产生超出不确定度的系统偏差 |
| REAL-07 | 全序列恢复 | 中断恢复与连续运行在数值容差内一致 |

R0 的连续保温帧默认不是“重复曝光”，因为结构可能随时间演化。REAL-02 需要额外的同状态重复曝光，或由独立证据证明某一时间段近似稳定后才能评估；缺少时标记 NOT TESTED，不得用相邻帧替代。

pilot 的 8 帧只用于问题发现、接口确认和阈值预检，不用于宣称总体准确率。完整序列的“可用率”分母是 120 个保温帧；PASS 和预先定义为“可带警告使用”的 WARN 计入可用，FAIL 不计入，并单独报告各状态数量。

- 用户可从四视图和 quality.json 理解失败原因。

**No-Go**

- 只能靠一个初值；
- 残差有系统结构却仍通过；
- condition 非有限或关键参数不可辨识仍输出高置信数值。

**工期**：7–12 日。

### P6：批处理、时间轴与可恢复性

**目标**：稳定处理 120 帧序列，并证明结果不依赖遍历方向或中断位置。

**任务**

- 固化 manifest schema：path/frame_id/order/time/dataset/frame；
- 时间优先来自实验日志，其次是明确声明的 provisional 时间；
- independent 和 warm-start 都保留；
- 失败帧不得成为下一帧初值；
- checkpoint 包含 input/config/mode/code/schema hash；
- 中断恢复不得重复污染已完成结果；
- 输出 lineage：每帧初值来自哪里；
- 首版保持顺序执行，不提前引入复杂并行；
- 不实现 global/shared joint fit。

**验收实验**

1. 4–8 帧 pilot independent；
2. 同一 pilot warm-start；
3. 正序与逆序 warm-start；
4. 注入一个读取失败、一个质量失败；
5. 中途取消并 resume；
6. 120 帧全序列 independent；
7. 120 帧 warm-start；
8. 比较连续运行与恢复运行。

**Go**

- 排序、时间和 selector 完全正确；
- independent/warm-start 差异落入不确定度或被标记；
- 正序/逆序无不可解释系统偏差；
- resume 与连续运行一致；
- 部分失败仍保留完整证据，进程返回码诚实。

**No-Go**

- warm-start 路径依赖未被识别；
- 失败结果传播；
- checkpoint hash 不匹配仍恢复；
- 使用 mtime 冒充正式实验时间。

**工期**：4–7 日。

### PF：独立物理正演路线

PF 不阻塞 0.2.0 经验测量平台，但阻塞任何“物理模型已实现”的声明。

#### PF-1 模块隔离

建议新增：

- src/butterfly_saxs/forward/grubb2016.py；
- src/butterfly_saxs/forward/lamellar_fft2021.py；

它们不得替换当前 intensity.py 经验模型，结果中必须标明 model_scope=physical_forward。

#### PF-2 Grubb 2016 递进实现

1. Eq. (7) 类线形和尺寸展宽；
2. 完美取向极限；
3. 绕层片轴的旋转平均；
4. Fraser 类三维取向积分；
5. 能量/取向分布与背景；
6. 数值积分收敛和极限情况；
7. 复现论文中圆弧、近直线、椭圆轨迹与完整二维图样的定性趋势；
8. 与经验模型在相同 q、mask、背景条件下比较。

实现时必须沿用精读文件中已经分开的 2016/2021 符号，不把不同论文中的 phi、theta、psi、alpha 混为同一物理量。

#### PF-3 Grubb 2021 独立生成器

- 实空间层片堆叠；
- 倾斜、旋转、间距分布；
- 2-point、eyebrow、butterfly；
- beamstop、streak、overlap、坏点；
- FFT/投影到 detector；
- 真值与图样一起导出。

#### PF-4 先正演，后考虑逆拟合

只有同时满足以下条件才讨论物理逆拟合：

- T2 中已知结构参数能够被可靠恢复；
- 真实数据有 WAXD/TEM/AFM/机械状态等独立约束；
- 多初值收敛到同一物理解族；
- 留出 q/角度区域预测通过；
- 不同物理模型的非唯一性已量化。

否则项目停留在“物理正演比较 + 表观二维测量”，这是科学上合格的结果，不是失败。

**工期**：10–20 日起，视积分模型和验证数据而定。

## 12. 总暂停条件

1. 原始数据 hash 变化；

8. 残差存在系统结构；
9. warm-start 正反序结果明显不一致；

## 15. 最终目标复述

本项目不是为了“让某张图被椭圆拟合上”，而是为了把二维 SAXS 图样转化为**有标定、有质量门、有不确定度、有证据链、能批量复现的表观测量结果**。Grubb 2016/2021 为项目提供了几何、ridge 和物理正演方向，但也提醒我们：二维椭圆轨迹具有非唯一性。

因此，最终成功应表现为：

- 软件能可靠处理真实 detector 数据；
- README 四视图能帮助用户发现拟合成功与失败；
- 自动流程既能给结果，也能拒绝不可信结果；
- 真实序列的趋势可复现、可追溯；
- 科学结论严格停在证据所支持的位置；
- 当独立物理模型和外部表征准备充分后，再从“表观测量”升级到“物理正演比较”，而不是直接跳到唯一结构反演。
