# 实空间片层工作台

实空间片层页把当前 SAXS 结果转换为**参数驱动示意**。二维投影和三维薄板使用同一份中心、尺寸、方向与顶点；它不是显微图重建，也不提供唯一的三维结构反演。

## 从当前结果开始

1. 在蝴蝶分析页完成一帧测量，切到“实空间片层”。工作台自动读取已有径向峰测量，不需要复制参数。
2. 默认“径向峰位”使用有效的 `lobe_radial_peaks`，按 `L_app = 2π/q_star` 计算表观周期。原有的方位环带代表 q 不参与换算。
3. 左上是观测 SAXS 与已有拟合叠加，左下是样品面内投影，右侧为可旋转的三维示意。面内坐标按 `draw_axis_deg` 旋转，使参考方向竖直；该设置不证明真实加载方向已经独立标定。
4. 使用“单堆栈 / 多堆栈”切换结构尺度，或选择 A/B 分支。原有数据缺少一个分支时，软件不会镜像补出另一个。
5. 拖动三维视图旋转，滚轮缩放；标准视角和复位按钮可恢复观察方向。“放大视图”暂时独占主画面，再次点击恢复布局。二维视图也支持滚轮缩放。

“参数来源与假设”显示值、单位、来源、状态及已有区间；详细记录用于回查原始文件、容器帧和分析条件。

## 参数的含义

| 控件 | 含义 |
|---|---|
| 径向峰位 | 使用原有窄角扇区径向剖面的峰位；先统一 nm⁻¹/Å⁻¹ 单位，再换算周期。 |
| 椭圆派生周期 | 沿用原点中心假设及容差，使用已有短轴派生周期或 `2π/b`；非零中心不产生该周期。方向仍来自观测峰，椭圆轴倾角不替代结构角。 |
| 手动示意 | 显式设定周期、单位和法向角度；状态始终说明是手动假设。 |
| 厚度 / 周期 | 默认 0.25，是绘制厚度，不能当作测得厚度或结晶度。 |
| 宽度、深度 / 周期 | 均默认 4，描述示意薄板的横向尺寸。 |
| 每堆栈层数、堆栈数量 | 默认 8 层、12 个多堆栈空间槽位；缺失分支的槽位留空。 |
| 方向分散 | 示意中固定随机样本的角度扰动范围，不是反演得到的取向分布或参数置信区间。 |
| 高级假设 | 包括深度、每层侧向错移、出平面倾角、随机种子及显示配色。 |

相反的 q 向量描述同一个无向法向。对向观测不一致会保留候选状态和原因，不把不一致解释成结构已被定量确定。无物理标定时只显示相对长度；已有参数的区间保留其原有定义，不自动升级为校准置信区间。

示意设置不回写拟合参数。撤销、重做以及“恢复数据驱动默认值”只影响新页面。更改图像、标定、mask、选区或分析设置后，旧示意失效，重新分析后再使用。

## 序列与已有结果

- 完成现有批处理后，结果会传给片层页；也可通过“导入结果”读取本项目的原生单帧 JSON/NPZ 或批次结果文件夹。
- 软件不猜测任意 CSV 的字段和单位。旧结果没有可追溯径向峰时会说明缺少输入；可以重新测量，或显式切到手动示意。
- 帧滑块、轨迹图和播放控件同步切换 SAXS 与片层场景。播放只经过真实帧，不插入模拟的中间实验状态。
- 同单位序列使用固定布局尺度、相机和随机样本。堆栈槽位在帧间保持身份，缺失/失败帧明确留空；图像按当前帧读取，不保留上一帧内容。
- 项目文件的可选 `lamellar_view` 保存示意设置、配色、视角和精简来源快照。旧项目可正常打开；与保存时输入状态不一致的场景不作为当前结果恢复。

可直接启动原生结果包：

```powershell
bsaxs-gui --no-auto-preview --lamellar-results "G:\my-results\manifest.json"
```

## 导出

当前帧导出包含二维 SVG/PDF、三维 PNG、组合图、设置 JSON、参数来源 CSV、几何 NPZ 和带文件哈希的清单。原生三维渲染可用时使用实际高分辨率渲染；无图形后端的 Python 导出使用同一几何的静态绘图。两者不能混称为原生渲染验证。

序列导出包括逐帧 PNG、GIF 和来源清单，保留帧顺序及缺失帧。导出使用新目录；已存在目标不会被覆盖。耗时导出可取消，未完成临时内容不会发布为完成结果。

图中的“参数驱动示意”“候选参数驱动示意”或“手动假设示意”说明会保留。三维出平面排列、厚度、横向尺寸和空间位置属于绘制假设。

## Python 接口

```python
from butterfly_saxs import (
    LamellarSettings,
    build_lamellar_scene,
    export_lamellar_scene,
    load_lamellar_sources,
)

sources = load_lamellar_sources("results/frame_0110.json")
scene = build_lamellar_scene(
    sources[0],
    LamellarSettings(mode="multi", stack_count=12, seed=7),
)
if scene.metadata["available"]:
    paths = export_lamellar_scene(scene, "results/lamellar-0110")
else:
    print(scene.metadata["message"])
```

场景数组的局部尺寸顺序是宽度、深度、厚度；`orientations` 的列是这三个局部方向，`vertices` 是实际薄板顶点。核心和导出接口不依赖 Qt。
