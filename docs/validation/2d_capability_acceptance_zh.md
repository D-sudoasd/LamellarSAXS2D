# 二维蝴蝶图样能力与验收边界

本项目只比较二维探测器图样的观测、拟合、质量判据和导出。固定 q 环的 `I(χ)` 与局部径向剖面属于二维图样的取证步骤；Guinier、Porod、散射不变量等通用一维 SAXS 分析不属于本项目范围。

## 当前已具备

- PONI 物理 q 几何、mask 与有效像素域；固定 q 环的角向花瓣轨迹、局部曲率和径向扇区三条互不混淆的观测路径。
- 缺瓣、断环、竞争峰、热像素和局部低覆盖不会自动镜像或插值成花瓣。观测点、逐环原始强度、计数、覆盖、候选峰和拒绝原因可追溯。
- 双椭圆使用固定的对角分支身份；逐弧留出检验与主 annular 拟合采用同一端点先验。近圆形轴向不可辨识、轴比碰界、长轴超出观测范围和花瓣触及 q 窗口边界会压低可报告性。
- 候选拟合保留四象限计数、相对侧边配对、中心对称偏差及状态；同一预设 q 环强制一致的半径不当作独立对称性证据。
- 批量、GUI 与图包保留工程结果和科学接受状态的区别。

## 尚需完成，才可声称二维能力全面领先

1. **同源基准。** 对同一批原始及校正帧使用相同 PONI、mask、q 窗口和人工审阅标签，比较花瓣定位误差、缺瓣误补率、近圆环误判率、重叠分支可辨识性、失败保留率和运行时间。含合成真值、实验重复帧及人工盲审；只报工程指标，不把拟合收敛当科学真值。
2. **图样分流。** 在报告双椭圆前区分有四侧连续轨迹、两侧/三侧局部支持、近各向同性环和无法分流的重叠/条纹。分流需要明确的二维观测证据与拒绝原因，不依据样品名自动赋予层片机制。
3. **局部二维形状。** 在有效 mask 内独立测量每个花瓣的径向与切向宽度和背景，并报告窗口、有效像素数、残差及模型失配；不得把局部模型的宽度当层片厚度。
4. **模型族比较。** 对称双椭圆与可选非对称二维强度模型在相同有效像素域上比较。增加参数必须通过留出图像/重复帧验证，防止更灵活的模型仅因自由度多而看似更好。
5. **真实数据科学门槛。** 对选定样品系列固定 q 校准、校正状态、反射级次证据与命名版本，审阅源帧和所有 WARN/FAIL。人工科学接受与程序工程通过分开记录。

2026-09-24 的 BL19B2 只读试验属于上述门槛的预检，不构成“全面领先”或可发表参数的证明。私有帧路径和数值记录在本地忽略目录 `results/validation/wing_2d_upgrade_20260924/`。
