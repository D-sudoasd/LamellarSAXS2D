# 连续层片序列验证

`scripts/validate_lamellar_sequence.py` 用两套有限实空间层片模型生成连续 SAXS 强度序列，并通过项目的曲率脊线、径向脊线和界面 annular trajectory 分析路径。模型生成器不导入拟合强度函数，也不从椭圆方程绘制目标图样。

第一套 T2 序列复用 `benchmark_t2.py` 的有限层片密度和二维 FFT。10 个信号帧的层间距从 11.4 nm 连续改变到 12.6 nm，取向分布宽度和中心角也连续变化。beamstop 对所有帧相同，第 6 帧增加局部缺瓣 mask。mask 只排除像素，源强度仍保留。该序列用于检验 q 位置、帧间连续性、缺失像素和噪声下的候选保留；它本身没有独立控制文献几何中的层片倾角与堆栈旋转。

第二套序列从二维实空间有限堆栈构造密度。每个堆栈由高斯层片组成，并乘以沿堆栈轴和其法向具有不同尺度的有限高斯包络。正、负层片倾角群体分别采用符号相反的堆栈旋转；倾角和堆栈旋转幅度随帧独立改变。对每个堆栈分别计算二维 FFT 功率，再对取向分布作非相干强度加权和。结构记录包含层间距、层片倾角、堆栈旋转、堆栈宽度/高度、层数、层片宽度及取向分布权重。该模型依据文献描述建立，用于检验有目的的蝶形轨迹提取；它不是 Grubb 的完整三维尺寸和取向分布积分模型。

两个主序列都按无噪声首阶位置附近环带像素的第 90 百分位强度标定加性高斯噪声，使该统计量与噪声标准差之比为 15。每帧记录实际噪声标准差、环带强度统计量和实测比值；噪声叠加后将强度截断为非负值。T2 另保留一个标准差为 0.025 的 `buried_signal_stress` 帧，用来呈现信号被噪声淹没时的结果；纯噪声对照使用主信号帧噪声标准差的中位数，不赋予结构 q₀。oblique 序列还包含相同结构的无噪声对照与匹配噪声对照。

验证分别报告三个量：结构周期给出的 `q0 = 2π / d`；从无噪声 FFT 强度、在已知 q₀ 邻域内独立进行环平均后提取的局部峰；以及应用从有噪声强度场提取的脊线/轨迹。曲率、径向和 annular 路径共用标准物理参数化；默认每帧使用 1 个初始值，`max_nfev=800`。初值数是可调的计算预算；报告分别记录请求配置和实际生效的配置。它不改变输入强度和残差定义，但可能影响收敛及候选参数。第二项是强度像素测得的可观测参照，不是盲测的一阶峰级次判定；解析投影点不作为测量目标。`q*`、`L = 2π/q*`、椭圆长短轴和轴比仍是不同观测量，不能互相替代。拟合失败、弱信号、缺瓣和噪声下出现的候选均保留并记录状态，不以单一通过率作为模型正确性的证明。

默认对 T2 和 oblique 全部帧运行 `butterfly_curvature`，对 T2 的首帧、缺瓣帧、纯噪声对照和 oblique 序列的首帧、缺瓣帧、无噪声对照、纯噪声对照运行界面使用的 `trace_method="annular_peak"`。还可用 `--radial-frames 0,5` 在 T2 的指定信号帧运行 pipeline `radial_peak`，或用 `--oblique-annular-frames 0,4,8,9` 选择 oblique annular 帧。默认还会在 128×128 网格上重新生成一帧相同结构、相同像素尺寸的 T2 对照。这会缩小实空间视场、增大倒空间像素间隔，也会改变有限窗口截断；它不是将 512×512 图像后处理降采样。该对照用于观察采样与有限视场改变后的曲率支持。annular q 环是角向采样坐标，不应解读成径向峰位。

从仓库根目录运行：

```powershell
py -3.13 scripts/validate_lamellar_sequence.py
```

结果写入被 Git 忽略的 `results/validation/upgrade_sequence/`：`summary.json` 保存模型参数、源码哈希、两套序列逐帧结果、强度参照、曲率与 annular 诊断；`sequence.csv` 提供合并的逐帧指标；两张 contact sheet 显示各模型的强度和排除 mask；两张 truth-vs-observed 图分别对照结构 q₀、无噪声环峰和脊线 q；annular 轨迹图及剖面图显示候选点、接受状态和强度剖面。默认输出若已存在，需显式加 `--force` 才替换脚本所知的输出文件。`--frames`、`--oblique-frames`、`--size` 和 `--seed` 可调整验证规模。

报告保存运行开始和结束的源码哈希，并标记运行期间是否发生代码变化。完整的径向候选峰、峰族及二维轨迹支持诊断均保留；拟合实际采用的弧点半径中位数与径向峰位分别记录。`demo_frames/` 保存 oblique 首帧、缺瓣帧和纯噪声对照的 NPZ、独立 mask 和结构参数 JSON。分析 pipeline 可直接读取 NPZ 中的物理 q 坐标与 mask；通用图片加载界面需另外加载 mask，并通过 qmap 接口提供物理坐标，不能将默认 pixel-q 当作 nm⁻¹。

## 文献依据与解释边界

- Grubb, Murthy & Francescangeli (2016), [Elliptical Small-Angle X-Ray Scattering Patterns from Aligned Lamellar Arrays](https://doi.org/10.1002/polb.23930)：层片堆栈取向、尺寸分布与散射强度建模背景。
- Grubb et al. (2021), [DOI 10.1016/j.polymer.2021.123566](https://doi.org/10.1016/j.polymer.2021.123566)：蝴蝶散射轨迹和曲率脊线分析背景。
- Murthy & Grubb (2024), [Evolution of elliptical SAXS patterns in aligned systems](https://journals.iucr.org/j/issues/2024/04/00/tu5052/) §3.1：层间距控制反射径向位置，层片倾角导致方位分裂，堆栈旋转与倾角符号关系影响 butterfly/eyebrow 形态，堆栈宽度和高度改变反射展宽；§4.1 讨论曲率轨迹。

这些合成运行验证的是实现面对已知、可控模型的行为。它们不代替真实实验序列的校准、误差评估或科学解释。
