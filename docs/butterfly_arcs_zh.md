# 蝴蝶花样：观测分弧与参数可辨识性

新工作流使用 `ridge_method = "butterfly_curvature"`。旧工程继续按保存的方法计算；选择新方法是一次明确的分析设置变更。

当前计算方法版本为 `butterfly-curvature-arcs-v2.1`。v2.1 修复了人工“包含区域”可能重新启用 mask 排除像素的问题，改进了径向选峰和宽峰候选噪声估计；外部 mask、非有限像素、既有 ROI 和 q 窗口保持为不可被编辑解除的约束。v2 修复了观测支持范围、状态生命周期和接口往返。旧版本结果应保留为历史对照，验证时记录实际方法版本与源码哈希。

## 从图像到椭圆

1. 在有效探测器像素上对强度面平滑，求最负主曲率及对应方向的斜率，定位亚像素脊点。处理尺度和强度缩放作为算法设置保存；显示对数变换不会改变计算输入。
2. 按原始轨迹连通性及局部方向形成弧段。相对于声明的参考轴和中心，QI+QIII 属于 A，QII+QIV 属于 B。上/下侧是每条斜椭圆自身长轴坐标的两侧，不是屏幕的上/下半幅。
3. 检查局部法向截面的强度、背景、峰形及定位误差。一个法向截面可以只观测到一个峰；不能因为模型具有两侧就强制把单峰拆成双峰。
4. 用共享中心、半轴及镜像倾角的两条椭圆描述已确认弧段。未知分支/侧别的点留在诊断图中，但不进入定量拟合。拟合不得逐点切换到距离最近的另一椭圆或另一侧。

拟合前会从观测点、局部方向、定位误差和采样尺度冻结有限的 q 空间支撑区域。该区域由矩形集合表示，保留断裂、排除点和端点；候选椭圆与这些区域的交集才是可投影范围，不能退回整条上半侧或下半侧。没有可行交集时保留有限的优化惩罚和候选参数，但 `projection_valid=false`，不生成虚假的有效投影坐标。

几何定义为

\[
E_\pm(t)=c+R(\beta\pm\theta_e)(a\cos t,b\sin t),\quad a\ge b>0.
\]

`a`、`b` 是长、短**半轴**；单位来自输入 q 标定。`beta` 是参考轴相对 +qx 的角度；`theta_e` 是表观椭圆轴倾角。它不自动等于结构中的层片倾角或堆栈旋转角。

## 结果应怎样使用

`candidate_fit` 保存优化候选值、残差、边界和分弧诊断。`quantitative_parameters` 逐个记录 a、b、b/a 和倾角的状态；证据不足时 `value=null`，候选数值保存在 `candidate_value`，以便继续诊断。

局部拟合协方差不是完整实验误差。图像级重采样重新执行平滑、取点、分支识别与拟合；相关点不能按独立观测直接 bootstrap。中央 95% 重采样范围在独立覆盖率验证以前仅称“经验区间”。半像素中心扰动是一项敏感性实验，不是已测得的仪器中心误差。缺少 PSF、校准不确定度或人工证据时保留对应的未评估状态。

当前质量筛查中的点数、残差/定位误差比和条件数阈值属于明确标识的临时工程阈值，不是从论文得到的普适准确度标准。`success=true`、工程 PASS 和人工 Accept 都不能替代独立科学证据门。

观测覆盖率按有支持的局部弧段累加，不把最大角度跨度当作已经测到的弧长。椭圆上的参数角覆盖与几何弧长覆盖也不相同；导出时保留定义及版本。

逐弧诊断包括法向残差、未加权 q 空间 RMS、基于观测参考中心的镜像对称性、端点及短弧依赖。留出预测使用与拟合相同的受限投影，并记录每条弧的有效/无效点数；不会只平均成功点或默默跳过第八条以后的弧。

## 使用顺序

在“蝴蝶分析”中载入图像、标定和 mask，先识别轨迹，再点选检查局部强度截面。圈选保留/排除区域或添加种子后重新识别；种子只能引导搜索有实际强度支持的脊线。查看两条椭圆的上下侧是否连续，随后评估参数。

分析设置和人工修正改变后，原结果失效；缩放、颜色和对比度仅重绘。批次共享设置，但每帧都重新判断拓扑和信号支持，不能用上一帧补齐本帧缺失弧。

人工审核状态与科学验收分开保存。可以导出未确定或失败候选的诊断证据；人工“接受”不会自动使半轴成为已通过科学验收的定量参数。导出时选择父目录，程序新建独立分析文件夹并保留已有文件。

Python 和 CLI 使用同一配置，例如：

```toml
[analysis]
ridge_method = "butterfly_curvature"
q_window = [0.1, 0.5]
draw_axis_deg = 90.0

[analysis.butterfly]
stage = "evaluate"
resamples = 32
sensitivity = true
seed = 20260906
edits = []
```

`stage="trace"` 仅识别和检查轨迹；`resamples=0` 不计算重采样区间。32 次是交互评估的初始预算，不能据此宣称已经校准了区间覆盖率。正式基准需保留独立验证样本及重复次数。

公共分析结果在 `analysis.butterfly` 中保留可重放配置；TOML 工程支持非空的交互编辑记录。Python 返回的非有限数在公开 JSON 边界转为 `null`。基准来源分别记录实际生成器源码哈希和 case/seed/shape 身份，避免将样本标签哈希误称为源码哈希。

## 文献对应与适用边界

- Wang, Murthy & Grubb (2007), Fig. 3 和正文：按象限配对的共享参数双椭圆；特定方向切片上的双 Gaussian 峰定位。[DOI](https://doi.org/10.1016/j.polymer.2007.04.026)
- Grubb et al. (2021), p. 5 的强度面方法，以及 Fig. 7、Table 3 的 butterfly 示例：强平滑后沿最负主曲率方向定位脊线，排除束挡、streak 和重叠区。表中 butterfly 示例 b/a 约 0.40，不能据此保证 b/a≈0.02 的准确性。[DOI](https://doi.org/10.1016/j.polymer.2021.123566)
- Grubb et al. (2016) 的完整三维取向/尺寸展宽强度模型属于另一条建模路线；当前 `full2d` 仍是已有经验模型。[DOI](https://doi.org/10.1002/polb.23930)

以上约束支持表观二维测量。单个花样并不唯一确定三维层片结构或材料变形机制。

## 调校与科研图

径向峰的选择使用局部峰突出度与有记录的稳健噪声估计。径向分箱必须有足够的连续支持；单个异常像素主导的分箱不会被当作可靠峰。低 q 处仍有未分辨的峰族时，返回不确定状态，不强行将较亮的高 q 峰命名为一阶。选择阈值、有效贡献数、候选峰和不确定原因保存在 `diagnostics.first_order_q_hint`。q 窗口及分箱方式仍会影响峰位；这些工程判据不证明谐波级次。

宽峰候选的噪声来自 mask 归一化平滑后的局部残差 `I - I_smooth`，仅使用有效且有足够邻域支持的样本。候选点的 3σ 门槛保持不变。花样整体强度起伏只用于曲率面的高度归一化，不再代替随机噪声。每个平滑尺度的估计方法、噪声值、样本数和不可估计状态保存在 `diagnostics.candidate_noise`；它不等同于完整实验不确定度。

界面可选择快速（0 次）、标准（32 次，默认）或扩展（128 次）图像重采样，并单独控制敏感性检查。识别阶段保持 0 次重采样，但记住随后评估的预算。快速结果不包含重采样区间，不能据此跳过科学验收。q 范围错误会提示并阻止启动分析；显示对比度变更仅重绘。

默认扁椭圆先验的 `b/a` 上限是 0.35。若已知待测对象超出此范围，应明确选择 `standard` 或依据实验设置边界；贴边结果继续降级为仅环，不自动扩大先验。已知真值基准也必须报告使用的先验，不能把先验截断造成的误差等同于取点精度。

`scripts/validate_butterfly_arcs.py` 支持 `--ellipse-preset standard`，该选择纳入 development/holdout 冻结匹配。真实帧走与应用一致的图像读取接口，可读取 CBF、EDF、TIFF、NPY 等格式；不要求文件编号固定为五位。复杂文件名可用 `--all-project-inputs`，按工程中明确列出的文件执行，不猜测编号。输入前后哈希与有效分析配置随报告保存；正、反两种 mask 的内容都纳入冻结检查，已有非空输出目录不会覆盖。

蝴蝶测量的矢量科研图和源数据导出见 [科研图指南](butterfly_figures_zh.md)。图稿样式不会改变拟合设置、原始强度或科学验收状态。
