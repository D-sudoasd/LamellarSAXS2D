# 0.4 发表画板

“实空间片层 → 发表画板”可以直接使用当前帧，输出平直片层的精细三维主图或 SAXS＋结构组合图。白色背景、哑光冷暖配色和微倒角都是绘图设置；拟合结果、片层中心、外包尺寸、法向、周期和数量保持不变。

## 操作

1. 打开已有结果或完成当前帧分析，切到实空间片层。
2. 选择单堆栈或多堆栈，再打开“发表画板”。默认自动选取兼顾两组结构的正交视角。
3. 选择结构主图或 SAXS＋结构；单栏为 89 mm，双栏为 183 mm，也可自定义宽、高。正文默认 6.5 pt、分图字母 8 pt、600 dpi、英文。
4. 可拖动取向族、分图字母、标题等文字。“采用工作台当前视角”保留工作台旋转与缩放；“平衡视角与自动取景”恢复自动构图。
5. 导出到新目录。预览采用较低像素数，正式导出在独立 Qt 场景中重新渲染并启用超采样；进度显示保存步骤，可取消。

结构主图把三维结构作为主体，局部特写展示一个真实堆栈中最多三片的层距与厚度关系。组合图另含当前 SAXS 和完整场景的 xy 投影。特写的裁切不会减少主图中的层数。自动标注可再拖动，以适应特殊角度或较大的方向分散。

## 图中量的含义

- `L_app` 来自已有径向峰位的 `2π/q*`；选择椭圆派生周期时标为 `L_ell`，手动周期标为 `L_set`。
- `t (... set)` 明确表示示意厚度设定。横向尺寸、数量、空间位置及随机分散仍是示意假设。
- 法向箭头沿场景中实际的示意法向。Reference 沿来源中记录的参考角度，经过相同相机投影；它不自动证明真实拉伸轴方向。
- 比例尺依据相机缩放和原始长度单位计算；没有物理标定时使用 `rel. u.`，不显示 nm。
- 候选、手动或参数驱动示意的状态以小型图注保留。精修不把候选参数变成正式量，也不把示意厚度解释为测得厚度或结晶度。

## 输出与复现

每次导出包含固定画板的 `figure.svg`、`figure.pdf`、`figure.png`、`figure.tiff`，独立三维渲染层 `native_3d.png`，以及图注、设置、来源表、原始场景数组和 SHA-256 清单。SVG 保留文字元素及命名分组；PDF 使用 TrueType 嵌入，三维表面作为高清图像，文字、箭头和比例尺为矢量。白底与透明输出采用相同几何，不做自动裁边。

项目的可选 `lamellar_view.publication` 保存样式、画板尺寸、实际坐标相机和标注位置；旧项目可以直接打开。切换帧或修改数据时，旧画板立即失效，直到当前场景和图像就绪。工作台序列保持固定相机、尺度及随机样本，仍然只播放真实实验帧。

Python 调用示例见 [examples/export_publication.py](../examples/export_publication.py)。新接口为 `PublicationStyle`、`PublicationFigureSpec` 与 `export_publication_figure(...)`，原有 `build_lamellar_scene` / `export_lamellar_scene` 接口保留。

Qt 图形后端不可用时，发表导出会明确报错；工作台原有的简洁二维／静态三维导出继续可用。不能把简洁导出或低分辨率预览声明为原生高清输出。

画板规格参考 [Nature 图稿准备](https://research-figure-guide.nature.com/figures/preparing-figures-our-specifications/)与[面板构建和导出](https://research-figure-guide.nature.com/figures/building-and-exporting-figure-panels/)。实际投稿还应按目标期刊与最终排版检查；这里的“发表画板”表示制作规格，不构成结构反演或期刊录用判断。
