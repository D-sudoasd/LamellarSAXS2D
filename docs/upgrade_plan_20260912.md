# 全链条升级工作记录（2026-09-12）

目标：提高蝴蝶花样处理的科学可靠性与速度，改善从载入、识别、评估到导出的交互，并提供由测量数组直接生成的科研图。保持已有人工编辑和科学可辨识性边界。

## 实施顺序与边界

1. 记录现有改动，运行原有测试；只读定位用户授权的真实数据、PONI 和 mask。
2. 独立检查算法与界面，依据可复现问题确定修改。性能比较保持输入、mask、参数和方法一致。
3. 优化分析核心并增加针对性回归验证，不降低科学门槛或用镜像补充观测。
4. 增加蝴蝶分析科研图：二维 SAXS 与有支持的轨迹为主图，诊断为辅助图；Python 绘图，固定画板，单栏 89 mm / 双栏 183 mm，正文 6.5 pt，可编辑 SVG/PDF 与高分辨率 TIFF/PNG，独立源数据及哈希清单。不得把候选参数当成科学验收。
5. 改进中英双语操作引导、结果状态和科研图入口，继续使用现有 Qt 栈及后台任务生命周期。
6. 独立代码复核；真实数据只读前后哈希、合成已知真值、CLI/Qt 与图稿视觉验证。将软件验证、实验调校及科学准确度验证分别报告。

现有 README.md、pyproject.toml、docs/assets/refinement-ui.png 和 scripts/capture_readme_ui.py 的未提交改动保留。无原始数据覆盖，无公开发布。
