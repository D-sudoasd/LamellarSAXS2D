# 拟合核查与峰值可视化完善

目的：回答“当前拟合是否可信”，并把二维实测图、几何候选、full2d 强度模型的几何、最强像素和散射峰连接成可检查的工作流。沿用 Python/Qt 与现有固定画板，不改写实验输入，不放宽科学接受门槛。

1. 核查同帧的几何残差、参数来源和 full2d 模型。区分几何脊线拟合与经验强度模型，不能把二者的椭圆混标为同一结果。
2. 补充可重复的峰值诊断：原始有效域最强像素、平滑信号的受支持峰、候选点及其 q/像素坐标、局部放大与径向/方位剖面。记录搜索域、mask、平滑和峰支持；不强行补足四峰。
3. 提供清晰的独立叠加图：实测强度＋几何候选，实测强度＋实际 full2d 椭圆；同时保留无叠加实测图和完整源数据。
4. 将峰值标记、峰表、定位交互和明确的拟合质量说明接入 GUI、CLI/Python 输出与批处理使用的公共结果。
5. 使用已有开发帧和未用于选择新参数的保留帧做检查，增加已知峰位、缺峰、mask/异常像素、单位和状态失效回归；独立代码复核后交付实际图包。

图稿论点是“观测特征与模型是否一致”，不是“拟合已证明结构”。主图＋峰位标记/局部诊断/残差各自提供独立证据。输出使用 89/183 mm 画板、可编辑 SVG/PDF、默认 600 dpi PNG/TIFF，包含曲线、峰表、剖面和哈希清单。

验证输出仅存放于忽略目录 `outputs/upgrade_20260912_followup/`。上一轮代码、报告和图包作为对照保留。
